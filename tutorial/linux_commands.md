# Basic Linux Commands

<details>
	<summary>📂 File & Directory Management </summary>
	<br>
	<div style="margin-left: 20px;">
	
	<details>
		<summary style="margin-left: 25px;"><code>ls -a</code></summary>
		<ul style="margin-left: 20px;">
			<li>Shows all files, including hidden (dot) files.</li>
		</ul>
	</details>

	<details>
		<summary style="margin-left: 25px;"><code>ls -l</code></summary>
		<ul style="margin-left: 20px;">
			<li>Long listing format; shows permissions and owners.</li>
		</ul>
	</details>

	<details>
		<summary style="margin-left: 25px;"><code>ls -h</code></summary>
		<ul style="margin-left: 20px;">
			<li>Human-readable; prints sizes like 1K, 234M, 2G.</li>
		</ul>
	</details>

	</div>
